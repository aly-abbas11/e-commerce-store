# VoltGear Prompt Library

Persistent workspace instructions should make prompts short.

## Feature

```text
/feature
Add <feature>. Reuse existing architecture. <important scope boundary>. Browser-QA if customer-facing. Stop after verification.
```

## Frontend

```text
/frontend-pass
Improve <surface> for professional electronics retail quality. Preserve data/business logic. Real media/data only. Verify 1440 and 390. Stop.
```

## Bug

```text
/bugfix
<symptom>. Reproduce, obtain exact stack/log, fix root cause, add regression coverage and stop after verification.
```

## Admin

```text
/admin-feature
Add <merchant workflow>. Reuse admin/data/media architecture. Validate server-side. Test create/edit/reload/visibility/authorization. Stop.
```

## Conversion audit

```text
/commerce-audit
Audit <journey> using the real rendered storefront. Rank only concrete opportunities by impact/confidence/effort. Do not implement yet.
```

## Security

```text
/security-gate
Review <scope>. Include relevant authorization, data exposure, web vulnerability, configuration and concurrency checks. Do not run destructive production tests.
```

## Infrastructure

```text
/infra-check
```

## Release

```text
/release
```
