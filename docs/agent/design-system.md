# VoltGear Retail Design System

## Desired character

Credible electronics retailer: calm, product-led, precise and easy to navigate.

## Visual hierarchy

1. product/category imagery;
2. product name/model;
3. price/variant/availability;
4. primary action;
5. secondary utility.

UI decoration must not compete with merchandise.

## Layout

Use consistent content width/gutters. Major sections should share alignment. Hero may be wider. Mobile should preserve fast category/product discovery.

## Product cards

Large clean image area, object-contain for isolated electronics, 1–2 line title, truthful review row only when real, obvious PKR price, truthful sale treatment, clear Add to Cart/Select Options. Avoid heavy enclosing borders/shadows.

## Category discovery

Use real category or representative product imagery. Labels should use customer language. Prefer obvious category access near the top of the homepage.

## Typography

Restrained sans-serif hierarchy. Avoid giant headings for routine commerce. Product information should scan quickly.

## Color/radius/shadow

Neutral foundation, current VoltGear accent sparingly, semantic states for errors/success. Moderate radius, few pills, minimal shadows.

## Motion

Use only when it clarifies interaction. Respect reduced-motion. Never make basic shopping dependent on animation.

## Copy

Prefer direct commerce language: Featured Products, Shop by Category, View All, Add to Cart, Select Options. Avoid generic AI lifestyle prose.
