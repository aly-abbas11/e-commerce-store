# Gadget storefront theme (Biometic cream / forest)

Applied on `/home2` + gadget chrome via `.gadget-theme`.

| Token | Hex | Role |
|-------|-----|------|
| Cream | `#F5F1E8` | Main canvas |
| Cream deep | `#EFEAE0` | Soft panels / trust pill |
| Forest | `#1F3626` | Primary CTA, dark sections, footer |
| Forest mid | `#25392A` | Dark section alt |
| Sage | `#8FA888` | Accent labels / highlights |
| Charcoal | `#1A1A1A` | Headlines & body on cream |
| White | `#FFFFFF` | Cards, text on forest |
| Taupe | `#8A8578` | Secondary text |

**Typography:** Fraunces (serif display) + DM Sans (UI/body).

**Pattern:** cream base · one forest statement section · forest CTAs everywhere · white cards.
