# Ecommerce Conversion

## Principle

Increase conversion by reducing uncertainty and friction, never by fabricating urgency or manipulating users.

## Audit journey

Traffic -> landing -> category/search -> PDP -> add to cart -> checkout -> order placed -> shipped -> delivered.

For each stage inspect:
- clarity of next action;
- information required for a decision;
- mobile friction;
- trust/policy visibility;
- form errors;
- performance;
- measurable event coverage.

## Pakistan/COD context

Placed orders are not equivalent to delivered revenue. When evaluating commerce success, distinguish placed, shipped, delivered and cancelled outcomes according to existing analytics/business rules.

## Recommendations

Rank opportunities by expected impact, confidence and implementation cost. Prefer high-confidence friction removal over decorative experimentation.

Never recommend fake scarcity, countdowns, reviews, popularity or misleading discounts.
