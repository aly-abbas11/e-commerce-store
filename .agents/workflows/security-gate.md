---
title: Security Gate
description: Perform a structured security review and remediation gate for the requested VoltGear scope.
---

Use `security-gate`.

Define scope and threat surface. Review auth/authorization, data exposure, mutations, uploads, sessions, web vulnerabilities, configuration and dependencies as applicable. Do not run destructive tests without approval. Rank findings and fix only within requested scope. Re-test. Report residual risk. Stop.
