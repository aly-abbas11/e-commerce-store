# Admin Operations Rule

VoltGear Admin is the merchant operating system. Favor clear, reliable workflows over decorative UI.

Admin changes should reduce merchant effort, prevent mistakes and keep operational truth visible.

Prefer structured CMS controls over arbitrary HTML/page-builder freedom. Reuse current media/product/category/order infrastructure.

For create/edit forms: validate server-side, preserve ordering deterministically, handle empty states, prevent accidental destructive behavior, and keep customer-visible consequences obvious.

Never delete products/orders/customers merely because a homepage/CMS relationship is removed.
