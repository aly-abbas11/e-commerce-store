# Frontend Retail Rule

Customer-facing UI must look intentionally designed for electronics commerce.

Reuse the shared ProductCard, Section, SectionHeader, typography/tokens and responsive containers where available.

Products and categories should dominate decoration. Prefer real catalog media, clean neutral surfaces, clear pricing, readable titles, direct CTAs and predictable controls.

Avoid AI-template signatures: excessive gradients, glass cards, giant shadows, random glow, decorative blobs, meaningless microcopy, too many pills, emoji and generic lifestyle prose.

No critical hover-only functionality on mobile. Preserve keyboard focus, semantic controls, touch targets and reduced-motion preferences.

Browser-QA customer-facing work at ~1440px and ~390px before declaring completion.
