# Core Execution Rule

One coherent task at a time. Understand before editing. Inspect targeted files, not the entire repository. Reuse existing architecture. Make the smallest coherent change. Fix problems introduced by the current task without asking routine questions. Stop when the requested task is complete.

Never expose secrets, start unrelated features, add paid services without approval, deploy production without authorization, or perform destructive data operations.

## Operator Intent Is Binding

If the operator explicitly requests a read-only or no-change task, do not create temporary files or make incidental repository changes merely to perform the inspection.
